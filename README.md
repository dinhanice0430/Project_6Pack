# 🏋️ GYM BOOKING

Website đăng ký kèo tập gym, chạy trực tiếp trên GitHub Pages.

## Tính năng
- Tạo kèo tập
- Chọn ngày, giờ, địa điểm, nhóm cơ
- Giới hạn số người
- Tham gia / rời kèo
- Tìm kiếm và lọc
- Responsive mobile
- Lưu dữ liệu bằng localStorage

## Chạy trên GitHub Pages
1. Tạo repository mới trên GitHub.
2. Upload toàn bộ file/thư mục trong project.
3. Vào Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: / (root).
6. Save.

> Bản này dùng localStorage để demo. Muốn nhiều người dùng chung dữ liệu online, cần thay localStorage bằng database như Supabase/Firebase.
